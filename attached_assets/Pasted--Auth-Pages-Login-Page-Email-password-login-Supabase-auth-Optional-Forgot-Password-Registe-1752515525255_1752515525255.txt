🔐 Auth Pages
Login Page

Email/password login (Supabase auth)

Optional: “Forgot Password”

Register Page (Optional – Admin only)

Create new users (for internal staff only)

You could skip public registration if users are added from an admin panel

🏠 Main App Pages (after login)
1. Dashboard Page
Summary cards (total projects, active tasks, overdue items)

Activity feed (recent uploads, task updates)

Quick actions (start new project, invite member)

2. Projects
Projects List Page

List of all projects (filter by status, client, team, etc.)

“Create New Project” button

Project Details Page (/projects/:projectId)

Overview: description, timeline, budget (placeholder)

Tabs or sections:

Tasks (linked to project)

Team

Documents

Comments (if included)

Client View toggle

3. Tasks
Tasks Board (Kanban View) (/tasks or inside each project)

Columns: To Do, In Progress, Review, Done

Drag-and-drop task cards

Filter by project, assignee

Task Details Modal or Page

Task description, assignee, due date, comments, attachments

4. Team Directory
List of team members

Role, email, contact info

Option to assign to projects or tasks

“Add New Member” (admin only)

5. Documents Page
Upload/view/download files

Organized by project and upload date

Supported types: PDF, images, design files

6. Client Portal View
Separate layout or dashboard (/client)

Show:

Their assigned projects

Project progress

Downloadable files

Timeline/status view

⚙️ Admin / Settings Pages
7. User Management (Admin Only)
List of all users

Add/edit roles

Deactivate/reactivate accounts

8. Account Settings
Profile edit (name, avatar, password)

Notification preferences (future feature)
